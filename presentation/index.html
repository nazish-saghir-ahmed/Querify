ENTERPRISE HARDENED DEFENSE

The JSqlParser AST Security Guard

Raw string regex checks are vulnerable. Querify uses formal Abstract Syntax Tree (AST) validation to guarantee zero mutation operations.

🚫 Strict Rejection Rules
  • ❌ Statement Chaining Blocked: Queries with multiple statements (SELECT 1; DROP TABLE...) are rejected.
  • ❌ DDL / DML Mutation Blocked: INSERT, UPDATE, DELETE, DROP, ALTER throw HTTP 403 Forbidden.
  • ❌ Table Isolation Guard: Querying unwhitelisted system catalogs (information_schema) triggers security audit blocks.
✓ Enforced Execution Controls
  • 🛡️ Enforced LIMIT 100: Protects database memory pool from runaway queries.
  • ⏱️ 5000ms Hard Timeout: Automatic cancellation via Spring Boot JdbcTemplate query timeout.
  • 📝 Immutable Audit Log: Every attempt—blocked or successful—is logged with timestamps and execution latencies.
